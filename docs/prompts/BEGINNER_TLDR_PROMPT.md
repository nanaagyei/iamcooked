# Beginner TLDR Prompt

## Goal

Generate a plain-English explanation of a security incident for AI-assisted builders and non-security experts.

## Tone

- calm,

- direct,

- helpful,

- non-alarmist,

- practical.

## Must Explain

- what happened,

- why it matters,

- who may be affected,

- what to do next.

## Avoid

- fearmongering,

- unexplained acronyms,

- vague advice,

- overconfidence,

- unsupported claims.

{

  "beginner_tldr": "",

  "why_it_matters": "",

  "what_to_do_next": [],

  "terms_explained": [

    {

      "term": "",

    }

  ],

  "confidence": "",

  "unknowns": []
