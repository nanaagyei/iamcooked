# Phase 01: Design Foundation

## Objective

Build the visual foundation before building product screens.

## Tasks

### 1. Tailwind Theme

Add custom tokens for:

- background

- surface

- border

- text

- severity colors

- radius

- shadows

### 2. Layout Components

Create:

- `MarketingLayout`

- `AppLayout`

- `DashboardShell`

- `PageHeader`

- `SectionContainer`

- `ResponsiveGrid`

### 3. Core UI Components

Create:

- `SeverityBadge`

- `ConfidenceBadge`

- `SourceBadge`

- `PackageBadge`

- `RiskMeter`

- `ActionChecklist`

- `EmptyState`

- `LoadingSkeleton`

### 4. Accessibility

Ensure:

- keyboard navigability,

- visible focus states,

- semantic headings,

- AA contrast,

- no color-only severity indication.

## Acceptance Criteria

- Components render in dark and light mode.

- Mobile layout is usable.

- Badges are visually consistent.

- Design feels premium, not generic.
