# Phase 05: Personalized Dashboard

## Objective

Give users a central place to track project risk and relevant incidents.

## Dashboard Sections

1. Project Risk Overview
2. Latest Relevant Incidents
3. Active Findings
4. Recommended Actions
5. Watched Packages
6. Digest Preferences

## MVP Dashboard

For MVP, users may not need full auth immediately.

Support anonymous scan reports first.

Later add:

- account creation,
- saved projects,
- GitHub connection,
- alert preferences.

## Acceptance Criteria

- Dashboard is responsive.
- Relevant incidents are prioritized over generic feed.
- Findings are easy to understand.
- User can update digest preferences.
